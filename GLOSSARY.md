# Glossary

**Enemy**
A hero on the opposing team in the current match. Up to six.

**Counter**
A shop item that is a good answer to a specific Enemy, plus a one-line reason explaining why. Belongs to exactly one Enemy hero; does not depend on who the player is playing.
_Avoid_: counter option, counter buy

**Counter List**
The full hand-authored set of Counters, across all heroes.

**Build Type**
The shop category the player is investing in this match: Weapon or Spirit, or unset. Influences how Counters are ranked, never which Counters exist.
_Avoid_: playstyle, role, hybrid (just leave Build Type unset)

**Threat**
An Enemy the player marks as especially dangerous this match (fed, or simply the one causing problems). Counters against a Threat weigh more.

**Recommendation**
A shop item suggested to the player, built from all the Counters that point at that item across the selected Enemies, ranked, and shown with each contributing reason.

**Item Category**
The shop section an item belongs to: Weapon, Vitality, or Spirit. Build Type is chosen from the Weapon and Spirit categories; Vitality items suit every build.

**Item Tier**
An item's shop price bracket (800 / 1600 / 3200 / 6400 souls), used to tell early answers from late ones.
